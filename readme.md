# HW1: Web Commercial Store
Welcome to the Commercial Store project for Semester 3 Web Development.


## Project Overview
This project is a simple online store built as part of the homework assignment. It demonstrates basic web development concepts including HTML, and CSS.


## Homework Instructions
- Allowed to be imaginary
- Branding
- Logo
- Menu
- Showcase
- Motto
- Multiple pages
- Graded based on visual quality and completeness


## Getting Started
1. Clone the repository.

2. Open `index.html` in your browser.

3. Explore the store features.
